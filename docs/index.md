# Documentation Home

Welcome to the sample product documentation. This set shows how a small doc set is organized so a new reader can go from zero to productive in one sitting.

## Start here
1. [Getting Started](getting-started.md) — install and verify the product.
2. [Workflow Automation Guide](workflow-automation-guide.md) — build your first automated process.
3. [PostgreSQL Quickstart](postgresql-quickstart.md) — set up the database the product runs on.

## Conventions used in this doc set
- Headings are task-based ("Create a database") rather than feature-based.
- Every procedure ends with a **Verify** step so the reader knows it worked.
- Warnings use a consistent format: **Warning:** followed by the risk and the fix.
