# Docs-as-Code Sample — Product Documentation Set

A small product documentation set written and maintained the docs-as-code way: plain Markdown sources, versioned in Git, structured for a static site generator (see `mkdocs.yml`), and reviewed like code.

## Skills demonstrated
- Markdown documentation authoring and information architecture
- Git-based writing workflow (branches, commits, reviewable changes)
- Task-based getting-started and workflow guides
- Database quickstart documentation (installation, configuration, backup)
- Consistent terminology, headings, and cross-linking across a doc set

## Contents
- `docs/index.md` — documentation home and map
- `docs/getting-started.md` — install, first run, and verification steps
- `docs/workflow-automation-guide.md` — automating a business process end to end
- `docs/postgresql-quickstart.md` — PostgreSQL install, first database, backup and restore
- `docs/healthcare-workflow-guide.md` — documenting a regulated workflow with audit steps
